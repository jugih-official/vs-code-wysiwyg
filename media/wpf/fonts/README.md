# Fallback fonts

Used only when the browser's machine lacks the Windows fonts the WPF panel uses (e.g. Linux browsers):

- **Selawik** (Microsoft, SIL OFL 1.1, `Selawik-LICENSE.txt`): open-source fallback for Segoe UI with matching metrics.
- **Carlito** (SIL OFL 1.1, `Carlito-OFL.txt`): metric-compatible with Calibri; also stands in for Calibri Light.

On Windows the real Segoe UI and Calibri are used, because the CSS names them first.
